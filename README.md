# 🏉 CleanTheClub — Rugby Club La Hulpe

Page d'inscription pour l'événement **CleanTheClub** du 5 juillet, aux couleurs du club.
Les inscriptions arrivent automatiquement dans un Google Sheet. Lien court + QR code inclus.

## 🚀 Démarrer

👉 **Suis le [GUIDE.md](GUIDE.md)** (pas-à-pas, sans connaissance technique, ~20 min).

En résumé :
1. **Héberger** la page (GitHub Pages) → adresse publique.
2. **Connecter** les inscriptions à un Google Sheet (Apps Script).
3. **Coller** l'URL Apps Script dans `assets/script.js`.
4. **Diffuser** le QR code (`assets/qr-cleantheclub.png`) et l'affiche (`affiche.html`).
